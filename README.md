# To-Do App

A simple To-Do (CRUD) app built with HTML, CSS and JavaScript.

## Features
- Add new tasks with a priority (Low, Medium, High)
- Edit and delete tasks
- Mark tasks as done
- Filter tasks: All, Active, Done
- Progress bar showing completed tasks
- Light and dark mode
- Tasks are saved in the browser (localStorage)
